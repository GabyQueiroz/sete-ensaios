# Sete Ensaios Depois do Fim do Mundo

Site de resultados da tese de doutorado de Talicia do Carmo Galan Kuhn (PPGECT/UTFPR), em parceria com o Grupo de Teatro Científico da UEPG.

O site traz a peça "Sete ensaios depois do fim do mundo", suas apresentações, registros de cena, a pesquisa com o público e um roteiro de criação para professores. A tradução para Libras é feita pelo [VLibras](https://vlibras.gov.br), ferramenta pública do governo federal.
